# Quick Puz – Privacy Policy

This repository hosts the official Privacy Policy webpage for the **Quick Puz** mobile application. It is structured for hosting via GitHub Pages to satisfy privacy policy requirements for app marketplaces such as Google Play Store and Apple App Store.

---

## 📱 About Quick Puz

**Quick Puz** is an offline puzzle game collection featuring:
- Sliding Tiles
- Lights Out
- Memory Match
- Flood It
- Picross and more

The app is privacy-friendly: it operates without user accounts, does not collect personal data, requires no sensitive device permissions, and saves progress locally on the player's device.

## 🚀 How to Enable GitHub Pages

To make the privacy policy publicly accessible via GitHub Pages:

1. Open your repository on GitHub: [`https://github.com/556bhonemyathein/quick_puz_poilcy`](https://github.com/556bhonemyathein/quick_puz_poilcy)
2. Go to **Settings** > **Pages** (under "Code and automation").
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and set the folder to `/ (root)`.
4. Click **Save**.
5. Wait 1–2 minutes for the GitHub Actions deployment to complete.
